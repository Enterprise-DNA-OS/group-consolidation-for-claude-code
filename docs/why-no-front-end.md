# Why there is no front end

The supplied workflow is a monthly finance review: read the source figures, map accounts, inspect currency translation, prepare elimination working papers and explain what prevents a period closing. Commands and private read-only HTML cover that work without a screen for every record.

Calxa also supplies reporting design, forecasting, connected accounting systems and other features outside this base. A web application adds visual account mapping, shared navigation, authenticated roles and immediate editing feedback. Mobile access, offline workflows and drag-and-drop mapping are not included here. Enterprise DNA scopes those features when building the customer's version.

The reports are views, not editing surfaces. Ask your coding agent for a change and inspect the resulting command output. Each document is generated from the database and branded through brand.json. Your finance owner remains responsible for interpretation, source reconciliation and accounting policies.
