Read CLAUDE.md. Explain actual minus budget in debit-positive convention. A positive revenue variance is unfavourable. Missing budgets stay blank. Posted eliminations affect actual only, so compare like-for-like budgets.

Run `npm run group -- budget-variance --period=<period>`. Substitute confirmed values and quote values containing spaces. Use `--json` when inspecting records programmatically. Present the returned evidence and any unresolved checks. Never send anything.
