description: Map a source account
---

Read CLAUDE.md. Read accounts and group-accounts first. A change invalidates source signoffs for that entity and is blocked while periods are locked.

Run `npm run group -- map-account --entity=<entity> --account=<account> --group=<group-code> --actor=<operator>`. Substitute confirmed values and quote values containing spaces. Use `--json` when inspecting records programmatically. Present the returned evidence and any unresolved checks. Never send anything.
