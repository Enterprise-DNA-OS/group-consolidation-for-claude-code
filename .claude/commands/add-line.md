Read CLAUDE.md. Use two decimal places at most. Posted journals cannot be edited.

Run `npm run group -- add-line --journal=<journal> --entity=<entity> --group=<group-code> --amount=<signed-group-amount> --actor=<operator>`. Substitute confirmed values and quote values containing spaces. Use `--json` when inspecting records programmatically. Present the returned evidence and any unresolved checks. Never send anything.
