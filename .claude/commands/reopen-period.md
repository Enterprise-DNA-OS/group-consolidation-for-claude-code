---
description: Reopen a reviewed period
---

Read CLAUDE.md. Obtain the authorised correction reason. Reopening is recorded in history and removes the current review signoff.

Run `npm run group -- reopen-period --period=<period> --reason=<reason> --actor=<operator>`. Substitute confirmed values and quote values containing spaces. Use `--json` when inspecting records programmatically. Present the returned evidence and any unresolved checks. Never send anything.
