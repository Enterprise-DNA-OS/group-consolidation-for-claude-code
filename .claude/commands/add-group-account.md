Read CLAUDE.md. Add --intercompany only for a separately identifiable internal balance. Finance approves the classification and translation policy.

Run `npm run group -- add-group-account --code=<code> --name=<name> --kind=<revenue|expense|asset|liability|equity> --rate-kind=<average|closing|historical> --actor=<operator>`. Substitute confirmed values and quote values containing spaces. Use `--json` when inspecting records programmatically. Present the returned evidence and any unresolved checks. Never send anything.
